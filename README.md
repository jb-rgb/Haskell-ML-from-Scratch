# [Nombre que elijas, ej: Haskell ML From Scratch]

k-NN and Feedforward Neural Network classifiers for the MNIST dataset, written in pure Haskell from the ground up.

## 🧠 Overview
This project implements mathematical models for pattern recognition and digit classification using the MNIST dataset. By strictly avoiding heavy Machine Learning libraries, this engine serves as a "white-box" study of the underlying linear algebra and functional data transformations that power modern AI architectures. 

## ⚙️ Core Features
*   **Pure Functional Paradigms:** High-order functions (`map`, `foldr`, `zipWith`) replace traditional iterative loops.
*   **k-Nearest Neighbors (k-NN):** Implemented using pure Euclidean distance metrics.
*   **Feedforward Neural Network:** (Work in progress) Forward propagation via native dot product and matrix multiplication.

## 🛠️ Tech Stack
*   **Language:** Haskell (GHC)
*   **Environment:** Tested on macOS / Ubuntu via GHCi
